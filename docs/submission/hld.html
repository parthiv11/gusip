Gujarat Police Innovation Challenge 2026 · GUSIP HLD · 21 August 2026

High-level design — keep the NVRs, share the hits

GUSIP sits beside existing cameras. Traffic, commissionerate, AMC, highway, railway, and the official Sentinel evaluation wall keep recording. We read streams, pull a still when needed, and publish a small event: who, where, when, plate, photo.

If a stolen Fortuner crosses five junctions in Ahmedabad and Gandhinagar, the operator should see one track — not five phone calls.

1. What we refuse to build

A statewide NVR (official Model 4). Copying ~80,000 continuous streams to one hall is a WAN and storage project, not an investigation project. Departmental VMS remains the system of record. GUSIP never writes PTZ or overwrites a local recording.

3. Two jobs the software must finish

Hit. Frame in → plate or person class → watchlist match → if that camera already has an open card, bump ×N. Else new alert + encrypted snapshot. WebSocket to the wall. Large pane switches. Target on the Paldi→Gandhinagar corridor: under 8 seconds.

Reconstruct. Officer picks a purpose (stolen vehicle, wanted person, evaluation…). Search will not run without it. Result is a GIS polyline of hops. Case folder can attach the latest alert. Export is blocked for operators.

6. Failure

If Surat’s VMS dies, Surat cameras go grey. Ahmedabad and Sentinel keep playing. Worker reconnects. Break-glass grants die when Redis TTL says so, even if the coordinator forgets to click End.
